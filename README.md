# Iniko Launcher

Bibliothek für die Spiele und Apps von Iniko: installieren, starten und automatisch aktualisieren.

## Herunterladen
Die neueste `InikoLauncher-Setup-….exe` unter **Releases** herunterladen und installieren.

Windows zeigt beim ersten Start eventuell „Der Computer wurde durch Windows geschützt“ –
dann auf „Weitere Informationen“ → „Trotzdem ausführen“ klicken.
